RouteNex

A logistics platform that runs rides, parcel delivery and a student shop from one fleet. It has dashboards for five roles, a route optimizer I wrote in pure Python that plans around vehicle capacity, delivery windows and priorities and shows before and after numbers, and three models for ETA, delay risk and demand. The assistant can prepare a booking, but nothing happens until you press Confirm. 95 automated tests. The models are trained on synthetic data and payments are simulated, so it is a demo. The live version is on free hosting, so the first load can take about a minute.

Python, FastAPI, SQLite, scikit-learn, Leaflet, Docker

Citewell

Ask questions about contracts and financial reports and get answers that point to the exact clause, table or page. If the documents don't have the answer, it says so instead of guessing. On my own 23-question test set it reached an MRR of 0.92 and a faithfulness score of 4.8 out of 5.

Python, FAISS, sentence-transformers, Streamlit, Groq
Live demoCode

Triavia

An emergency triage assistant. You enter a patient's vital signs and it returns one of four urgency levels, a suggested action and the factors behind the result. Safety rules can raise the model's answer but never lower it. It has 126 automated tests. It is trained on synthetic data, so it is a demo and not a medical tool.

Python, FastAPI, scikit-learn, Streamlit
Code

ChurnScope

Predicts which telecom customers are likely to leave and explains each prediction with SHAP. Trained on the 7,043-customer Telco dataset with a ROC-AUC of 0.856. Comes with a FastAPI service, a Streamlit dashboard and a Docker setup.

Python, LightGBM, SHAP, FastAPI, Docker
Code

LiftLab

A dashboard for reading A/B test results. It checks the data for sample ratio mismatch first, then runs frequentist and Bayesian analysis, plans sample sizes and monitors a test day by day. You can paste numbers or upload a CSV. 59 tests cover the statistics.

Python, SciPy, statsmodels, Plotly, Streamlit
Code

VigiRail

Predictive maintenance for railway rolling stock. A simulated sensor feed is scored by a Random Forest model, and four user roles see different views of the same data. It installs as an app on a phone and has 49 tests across backend and frontend. Trained on synthetic data.

Python, FastAPI, scikit-learn, React
Code
